PixelFx → Unity · Windows x64 휴대용 버전

실행
1. 이 ZIP 파일을 원하는 폴더에 모두 압축 풉니다.
2. "Start PixelFx.vbs"를 더블 클릭합니다. (Windows Script Host가 차단된 PC에서는 "Start PixelFx.bat"을 사용하세요.)
3. 기본 브라우저에서 앱이 열립니다. 인터넷이나 Node.js 설치는 필요하지 않습니다.

종료
"Stop PixelFx.vbs"를 더블 클릭하면 로컬 서버를 종료합니다.

앱은 127.0.0.1 로컬 주소에서만 실행됩니다. 이 폴더를 이동해도 실행할 수 있습니다.
폴더 안의 dist, runtime, server.cjs 파일을 따로 옮기거나 삭제하지 마세요.

PixelFx effects are from https://github.com/patch-gg/pixelfx and licensed under MIT.
Node.js runtime version and license are included in runtime/.
